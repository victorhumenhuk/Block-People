Privacy

Blocked terms and mode are stored in browser extension storage and may sync through the browser if sync is enabled. The extension does not make network requests, load remote scripts, track browsing, or use accounts.

Whole-word matching is always on for space-delimited scripts so blocking "art" does not match "start". CJK terms are matched directly.

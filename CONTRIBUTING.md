# Contributing

Thanks for considering a contribution.

## Setup

```sh
npm install
npm run lint
npm run build
```

Load `dist/chrome` as an unpacked extension from `chrome://extensions`.

## Branches

Use short, descriptive branch names:

- `fix/redaction-edge-case`
- `feature/import-export`
- `docs/privacy-update`

## Commits

Use concise imperative commit messages, for example:

- `fix: preserve text around redactions`
- `docs: clarify storage behavior`

## Issues

When filing an issue, include the browser, extension version, steps to reproduce, expected result, actual result, and any console errors.

## Pull requests

Keep pull requests focused. Include what changed, why it changed, and how you tested it. Screenshots are useful for popup or options UI changes.

Response time is best effort, not guaranteed.

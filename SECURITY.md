# Security

Block People & Keywords runs locally in the browser and does not process remote data on a server. Security reports are still welcome.

## Reporting a vulnerability

Email `victor@thesmios.com` with:

- A description of the issue.
- Steps to reproduce.
- Browser and extension version.
- Any proof-of-concept details that are safe to share.

Please do not open a public issue for a vulnerability until it has been reviewed.

Response time is best effort, not guaranteed.
